# Palgwae clean-room origin

This repository is the generic, clean-room implementation of Palgwae's
evidence-bounded graph methodology.

It intentionally contains:

- a fictional retail pipeline;
- generic entity and relation names;
- repository-relative evidence paths;
- no cloud credentials or runtime payloads;
- no private graph snapshots.

Contributors must not submit:

- private company, customer, account, bucket, table, queue, or job names;
- private repository URLs or commit revisions;
- production logs or inventories;
- source excerpts without redistribution permission;
- an exported graph from a private system.

When demonstrating a real integration, create the smallest synthetic fixture
that exercises the same parser behavior.
