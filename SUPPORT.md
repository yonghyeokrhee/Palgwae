# Getting help

For installation or query failures, open a
[bug report](https://github.com/yonghyeokrhee/Palgwae/issues/new?template=bug.yml).
Include your version, operating system, command, and a minimal fictional DAG.
Please remove internal identifiers and credentials. Graph bundles can reveal
architecture even without source excerpts.

For a new input format, use the adapter proposal form. For an unproven path,
use the evidence-gap form. `UNKNOWN` is a useful result: explain which declared
relationship you expected and which evidence could support it.

Security reports go through the private channel in [SECURITY.md](SECURITY.md).
This is a volunteer-maintained alpha without a response-time or production
support guarantee. Questions and small reproducible examples are welcome.
